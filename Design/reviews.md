## Running a new round

1. List the Open and Leaning items from the component rules and `decisions.md`.
2. Make sure each has something to judge: a Design Lab page for anything visual or animated.
3. Build a review page in the same format, one topic per question, and note where to test it.
4. When it's answered, record the outcome in `decisions.md`, update the rule files, and add the page here.
