Proposal stage

This is today's Rounds page, and the most important screen in Hatch, because it is where you try the new features before they exist in Echo. Below is a working prototype, not a picture. Switch specimens, change the compare mode, scenario and appearance, turn on redlines, and see how it feels. The decisions after it cover every part of this screen in detail. In Hatch this stage opens in its own window, as the next section explains.

Prototype of the recommended stagetoast sample, inventedTry: change Compare, press Space to flip, pick a scenario, switch appearance. The stage follows your picks: panels that fold away (H1) and a filmstrip when there are four or more options (H2). Try Demo: 5 options in the controls.

Data, sync and the agent contract

SQLite is the local database with proper indexes and full-text search. GitHub Issues in a private repo hold the tickets. Hatch syncs them with code, and every sync is recorded. Agents talk to Hatch through one command and never edit state.

The hatch command agents use

Each command validates the move, writes SQLite and GitHub, records the sync, and answers with the exact next step. An agent never has to remember a procedure.

CommandWhat it doesReturns
